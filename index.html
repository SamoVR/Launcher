SamoLauncher

One place for my games and RIFT Engine, plus your friends and what the community makes with it.

Download for Windows Windows 10 and 11. No administrator rights needed.

The launcher is invite-only for now, so you'll need a code to sign in.

What's inside

Library
Install, update and play with one button. Games still being built carry an Early access tag, so you know what you're getting.
RIFT Engine
Download the engine, see what changed and open the editor from the same place.
Community
Toolbox models, Lua plugins, materials, packs and templates made by RIFT creators.
Friends
See who's online and what they're playing, send messages, start group chats and invite people to a game.
Profiles
Levels, badges and a point shop. Your level is worked out on the server, so a high one means something.
Live updates
The launcher tells you when a new version is out and installs it when you restart.

Safety

  • Every download is compared with its published checksum. If it doesn't match, it's thrown away.
  • Community uploads are limited to a short list of file types. No programs, ever.
  • A moderator checks every upload and every new version before anyone can download it.
  • Private messages stay private. Staff only see one if someone in that conversation reports it.

The installer isn't code-signed yet, so Windows SmartScreen may warn you the first time you run it. Choose More info, then Run anyway. The version number and checksum are on the release page.
