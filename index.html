Samo Launcher

Games, RIFT Engine and friends in one launcher.

Install and play games by SamoVR, build your own in RIFT, and see who's online. It's in private beta on Windows.

Download for Windows

Windows 10 or 11, 64-bit. You'll need an invite code.

Your library

Install, update and play from one place. The server counts your playtime and levels, so a level means someone really played.

RIFT Engine

Get the engine here, then add models and plugins made by other creators. A person checks every upload before anyone can download it.

A profile that's yours

Show your favorite game, your badges and what you're listening to. Earn points by playing and spend them on frames, themes and sounds.

Friends in the same place

Message friends, start a group, and invite people straight into a game.

Before you install

Invite code
The beta is invite-only. Ask SamoVR for a code, then enter it after you create your account.
Windows may warn you
The installer isn't code-signed yet, so Windows can show a blue warning. Choose More info, then Run anyway.
